# app-development-and-testing

In order to download all npm project required packages:

> npm install

In order to download all python project required packages:

> python -m venv venv
> - .\venv\Scripts\Activate.ps1 
> - pip install -r requirements.txt

# Starting the backend part

This project contains Backend part on Uvicorn. In order to start it:

> python -m uvicorn main:app --reload

# Starting the Frontend part

This project contains Frontend part using Vite. In order to start it:

> cd frontend
> - npm run dev
